## What FieldMark is, briefly

A B2B SaaS platform that identifies HCPs (Healthcare Professionals — physicians, researchers) who matter or will matter in specific therapeutic areas, for MSL field intelligence.

Current TA focus: NSCLC (non-small cell lung cancer) for the demo push. Architecture supports Oncology, Hepatology, Immunology, Rare Disease.

The product surfaces HCPs ranked into cohorts:
- **Established** — current KOLs ("who matters today")
- **Rising Star** — emerging investigators ("who matters next") — *being reframed*
- **Community / Workhorse** — high-volume practicing physicians
- **Social / DOLs** — digital opinion leaders
- **Dark Horse** — currently deprecated

Each HCP has a detail page with cohort score, decomposed sub-signals, evidence, narrative, drug engagement, publications timeline, research themes.

### Cursor prompt structure that works

Garrett pastes our prompts into Cursor. Cursor sometimes silently no-ops or partially applies. The prompt patterns that consistently land:

```
=== CURSOR PROMPT — [BRIEF NAME] ===

Code only. Don't execute. STOP if ambiguous.

CONTEXT
[1-3 sentences explaining what we're doing and why]

FILES TO MODIFY
- [exact paths]

CHANGES
[Numbered steps with concrete code examples]

ABSOLUTE CONSTRAINTS
- [things NOT to do]
- [things to preserve]

=== END CURSOR PROMPT ===
```

Key tactics:
- **Pipe to clip when reasonable** — for verification queries, `| clip` to make copy-paste easy: `Get-Content "file" | Select-String -Pattern "..." | clip`
- **Always confirm edits landed** with `Select-String` or `git diff` before trusting Cursor
- **Verify schema column names** before writing Cursor prompts — multiple failures from assumed names
- **No multi-statement SQL transactions** in Supabase web editor — they give misleading results. Run statements standalone.
- **Plain ASCII over Unicode** in Python string constants (em-dash corruption in Cursor-generated code)
- **New tables via raw SQL require:**
  ```sql
  GRANT SELECT ON table_name TO anon, authenticated;
  NOTIFY pgrst, 'reload schema';
  ```
  RLS policies alone are insufficient. Often easiest to disable RLS:
  ```sql
  ALTER TABLE table_name DISABLE ROW LEVEL SECURITY;
  ```

## Critical context: things to know

### CT.gov data ceiling on trial investigators

Industry-sponsored trials systematically omit named investigators in CT.gov v2 API. `overallOfficials` returns 0-1 per trial. `responsibleParty` returns `type: SPONSOR` for industry trials with no named investigator. **Do not run `backfill_trial_investigators.py`** — confirmed Jun 5 across 5-trial sample.

This is why Trial Score was deprecated as a primary metric and Influence Score architecture was built instead.

### Open Payments has structural reporting lag

CMS Open Payments reports annually with ~12-month lag. Drug Engagement / Top Pharma Companies thresholds adjusted accordingly (24mo active, 48mo dormant). When a drug shows "stale" it may be active but not yet reported.

### OpenAlex misattribution and `conflation_suspected`

~4.6% of HCPs in `hcp_openalex_authors` are affected. `hcps.openalex_author_id` is denormalized convenience and intentionally non-unique. Conflation heuristic catches legitimately prolific HCPs (100% false-positive rate in spot check) — view `hcp_author_metrics_for_cards_v2` bypasses the filter.

### Career Years was dropped, intentionally

Today's methodology change removed Career Years as a ranking input. It's not in v3. If Career Years appears in any downstream analysis, that's a leftover bug.

### Network influence percentiles use continuous rank formula

Earlier implementation had percentile compression bug (top ~940 all = 100). Fixed via `100 * (1 - position/(n-1))` rounded to 2 decimals. If percentile values look truncated again, check the formula.

### Edge weight filter `>=2` was REJECTED for network centrality

Advisor explicitly rejected. Would destroy global network structure since major guideline/landmark papers have many co-authors with low individual edge weights.

### Pharma scoring is informational, NOT in ranking

7% of US Established cohort has Pharma data. Including it created fairness issues (advisor diagnostic ran 60/25/15 vs 50/35/15 vs Pharma-out — Pharma-out was correct). Pharma displays at parity in the UI but does not drive `cohort_score`.

### MSLs scan, don't play

The biggest UX learning of the day. Force-directed graphs, interactive visualizations, expandable widgets — all rejected for chip lists, KPI tiles, and static info. Static info beats interactive demos for field use.
