# FieldMark Design Tokens (captured from live UI — Riely profile, 2026-07-22)

## Palette
- **Background:** near-black, ~#0a0a0a (very dark, premium)
- **Cards/panels:** dark lifted, ~#141414–#1a1a1a, subtle rounded corners, thin/no borders — separation by CONTRAST not lines
- **Primary accent — AMBER/GOLD** ~#E0A82E: FIELDMARK wordmark, the "100" score, primary CTAs (Add Insight), key numbers/emphasis. Used SPARINGLY.
- **Secondary accent — BLUE/INDIGO:** score progress bars (Scientific/Network Influence), secondary buttons (Add context, Report data issue)
- **Cohort chips:** small uppercase pills. Established = muted GREEN "EST 98/99". (Rising Star / Dark Horse / Community presumably have own colors — confirm.)
- **Text:** headers muted gray (small-caps, letter-spaced); body light-gray.

## Typography
- Clean sans-serif, generous spacing.
- **Section headers:** SMALL-CAPS / UPPERCASE, letter-spaced, muted gray ("IDENTIFICATION", "WHY THIS EXPERT", "SIGNAL SUMMARY", "TOP PHARMA COMPANIES", "ENGAGEMENT MIX").
- Body: comfortable light-gray, readable.

## Data treatment
- Right-aligned values (dollars, scores, ranks).
- Restrained micro-charts: donut (Engagement Mix), horizontal progress bars (scores).
- Terminal-like, dense but calm.

## Trust / provenance affordances (SIGNATURE — audience distrusts black boxes)
- "View on NPI Registry →", "SHOW EVIDENCE", inline percentile citations, "co-authored papers" links.
- Every claim feels sourced/defensible.

## AI treatment
- Subtle sparkle marker "✦" (e.g. "✦ BRIEF" chip). AI/synthesis marked tastefully, NOT gimmicky.
- "Capture your field insight. Private to you." — quiet, trustworthy microcopy.

## Mood
Clinical, calm, dense-but-readable, premium field-medical intelligence tool. Bloomberg-terminal-meets-Nature.
